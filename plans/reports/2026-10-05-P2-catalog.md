## Classification decisions

- **CP1** — core idea-validation fields are `required` (13); supporting/refinement fields are `recommended` (9); none `supplemental`.
  - Required: idea name, primary customer, main problem, problem severity, current alternatives, required improvement, solution description, solution mechanism, riskiest assumption, MVP definition, MVP test plan, MVP pass/fail, evidence & assumptions.
  - Recommended: team name, team members, non-priority customer, role breakdown, customer story, alternatives analysis, core features, out-of-scope, revenue model.
- **CP2** — auto-fail items are `required` per plan: `cp2_expert_interviews` (≥2 experts, ≥6 months), `cp2_survey` (≥100 respondents), `cp2_ai_disclosure`.
  - Required (22): all non-optional proposal sections + cross-cutting mandatory items (AI disclosure, Harvard referencing, appendix, format).
  - Recommended (2): debate defense, debate attack.
  - Supplemental (2): pain point interviews, competitor criteria table (both explicitly `[Optional]` in plan section 9).
